# بوت حارس المجموعات العربية

بوت حماية لمجموعات Telegram مكتوب بـ Python و aiogram، ويشمل:

- تحققًا بسيطًا للأعضاء الجدد عبر أزرار عشوائية.
- مكافحة الروابط والإعلانات للحسابات غير الموثوقة.
- مكافحة التكرار والرسائل السريعة.
- فلترة الكلمات والعبارات الممنوعة.
- نظام تحذيرات وعقوبات تلقائي.
- أوامر إدارة للمشرفين.
- سجل مخالفات وإحصاءات في SQLite.
- رسالة ترحيب وقواعد قابلة للتعديل.

## 1) إنشاء البوت

1. افتح [@BotFather](https://t.me/BotFather).
2. استخدم `/newbot` وانسخ التوكن.
3. أضف البوت إلى المجموعة بصلاحيات **حذف الرسائل، حظر الأعضاء، تقييد الأعضاء، وإدارة الدردشة**.
4. انسخ `.env.example` إلى `.env` وضع التوكن:

```bash
cp .env.example .env
# حرر .env
```

## 2) التشغيل المحلي

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python bot.py
```

## أو عبر Docker

```bash
docker build -t telegram-guard .
docker run -d --name telegram-guard --restart unless-stopped \
  --env-file .env -v "$PWD/data:/app" telegram-guard
```

## أوامر المشرفين

- `/rules` عرض القواعد.
- `/setrules النص` تغيير القواعد.
- `/setwelcome النص` تغيير رسالة الترحيب.
- `/warn` تحذير العضو المشار إلى رسالته.
- `/unwarn` إزالة تحذير.
- `/warnings` عرض تحذيرات العضو.
- `/mute [دقائق]` كتم العضو المشار إليه.
- `/unmute` فك الكتم.
- `/ban` حظر العضو المشار إليه.
- `/unban رقم_المستخدم` فك الحظر.
- `/filterword كلمة` إضافة كلمة ممنوعة.
- `/unfilterword كلمة` حذف كلمة ممنوعة.
- `/filters` عرض الكلمات الممنوعة للمشرفين.
- `/settings` عرض إعدادات المجموعة.
- `/stats` عرض إحصاءات الحماية.

## ملاحظات مهمة

- يجب أن يكون البوت مشرفًا كي يستطيع الحذف والكتم والحظر.
- تحقق الأعضاء الجدد يعمل فقط عندما تكون صلاحية تقييد الأعضاء متاحة.
- قاعدة البيانات محلية في `guard.sqlite3`، لذلك احفظ مجلد البيانات عند استخدام Docker.
- لا تشارك `BOT_TOKEN` مع أي شخص. إذا تسرب، أعد توليده من BotFather.
